# Lipa: učenje slovenščine

Spletna stran za učenje slovenščine v stilu Busuu (A1–C1 + fraze za družino).

## Struktura
- `index.html` – postavitev strani
- `css/style.css` – dizajn
- `js/content-*.js` – vsebina tečajev (besede, dialogi, slovnica)
- `js/content-family.js` – fraze za obisk družine (sem dodajaš svoje izraze)
- `js/stories.js` – zgodbe z nadaljevanjem
- `js/game.js` – sklonska igra (samostalniki in stavki)
- `js/cloud.js` – prijava, sinhronizacija in "Us" (izzivi za dva)
- `js/config.js` – naslov in ključ za Supabase
- `js/app.js` – delovanje aplikacije
- `supabase.sql` – baza za Supabase (zaženeš enkrat)

## Objava
Brez build koraka. Na Vercelu: Framework Preset **Other**, ostalo prazno.
