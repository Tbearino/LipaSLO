# Lipa: učenje slovenščine

Spletna stran za učenje slovenščine v stilu Busuu (nivoja A1 in A2).

## Struktura
- `index.html` – postavitev strani
- `css/style.css` – dizajn (barve, pisave)
- `js/content-a1.js`, `js/content-a2.js` – vsebina tečaja (besede, dialogi, slovnica)
- `js/app.js` – delovanje aplikacije

## Objava
Brez build koraka. Na Vercelu: Framework Preset **Other**, ostalo prazno.
